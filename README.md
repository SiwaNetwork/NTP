# NTPD-RS - Интерфейс пользователя для NTP-сервера

Современный веб-интерфейс для мониторинга и управления NTP-сервером `ntpd-rs`, разработанный на языке Rust.

## 📦 Что входит в проект

### Основной модуль: `ntpd-ui/`

Полнофункциональный веб-интерфейс, состоящий из:

1. **Frontend (Dioxus WASM)**
   - Реактивный интерфейс на Rust
   - Компилируется в WebAssembly
   - Работает в браузере

2. **Backend (Axum HTTP Server)**
   - Читает данные из Unix Socket демона
   - Предоставляет REST API
   - Отдает статические файлы фронтенда

3. **Функции**
   - Real-time мониторинг метрик
   - График стабильности времени
   - Предиктивная аналитика (прогноз ухода часов)

## 🚀 Быстрый старт

Подробные инструкции по запуску см. в [ntpd-ui/README.md](ntpd-ui/README.md)

### Краткая версия:

```bash
# 1. Собрать фронтенд
cd ntpd-ui
dx build --release --platform web

# 2. Запустить сервер
cargo build --release --features backend
./target/release/ntpd-ui-server

# 3. Открыть в браузере
# http://localhost:3000
```

## 🏗 Архитектура

```
NTP Daemon (ntpd-rs)
    ↓ (Unix Socket)
HTTP API Server (Axum)
    ↓ (HTTP /api/status)
Web Interface (Dioxus WASM)
```

## 🛠 Технологии

- **Rust** - язык программирования
- **Dioxus** - UI фреймворк (аналог React)
- **Axum** - HTTP сервер
- **WebAssembly** - выполнение в браузере
- **Tokio** - асинхронный runtime

## 📁 Структура проекта

```
.
├── ntpd-ui/          # ← ВАШ ПРОЕКТ (веб-интерфейс)
│   ├── src/
│   │   ├── main.rs   # Frontend (Dioxus)
│   │   ├── server.rs # Backend (Axum)
│   │   ├── math.rs   # Линейная регрессия

```

## 📝 Примечание

Проект `ntpd-ui` разработан как интерфейс для существующего NTP-сервера `ntpd-rs`.
Остальные папки (`ntpd/`, `ntp-proto/`, `docs/`) являются частью базового проекта
и использовались как справочный материал и источник типов данных.
