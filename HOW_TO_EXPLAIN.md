# Как объяснить проект новичку (для защиты)

## 🎯 Одна фраза

**"Это веб-интерфейс для мониторинга NTP-сервера, написанный полностью на Rust и работающий в браузере через WebAssembly."**

---

## 📖 Подробное объяснение (3 минуты)

### Что это такое?
"Интерфейс для наблюдения за работой сервера синхронизации времени. Показывает, насколько точно настроены часы компьютера, откуда берется время, и предсказывает, как будут вести себя часы в будущем."

### Как это работает?
1. **Демон NTP** собирает данные о времени и записывает их в специальный файл (Unix Socket)
2. **HTTP сервер** (написан на Rust) читает эти данные и отдает их через интернет
3. **Веб-интерфейс** (тоже на Rust, компилируется в WebAssembly) показывает эти данные в браузере

### Почему Rust?
- **Безопасность**: Невозможно сделать ошибку с памятью (компилятор не даст)
- **Скорость**: Работает так же быстро, как программы на C++
- **Современность**: Можно писать и сервер, и интерфейс на одном языке

### Что умеет интерфейс?
- Показывает текущее смещение времени (насколько часы спешат/отстают)
- Рисует график стабильности за последнюю минуту
- **Предсказывает**, каким будет смещение через час (используя математику - линейную регрессию)

---

## 🔧 Технические детали (если спросят)

### Frontend (main.rs)
- **Dioxus** - фреймворк для UI (как React, но на Rust)
- **WebAssembly** - код компилируется в формат, который работает в браузере
- **Реактивность** - интерфейс автоматически обновляется при изменении данных

### Backend (server.rs)
- **Axum** - HTTP сервер для Rust
- **Unix Socket** - читает данные от демона
- **REST API** - отдает данные в формате JSON

### Математика (math.rs)
- **Линейная регрессия** - метод наименьших квадратов
- Анализирует последние 60 точек данных
- Вычисляет тренд (куда "ползут" часы)
- Предсказывает будущее значение

## 💡 Простые аналогии

### Для объяснения WebAssembly:
"Представьте, что вы написали программу на Rust. Обычно она работает только на вашем компьютере. Но WebAssembly позволяет этой же программе работать прямо в браузере, как JavaScript, но быстрее."

### Для объяснения реактивности:
"Как в Excel: когда вы меняете число в одной ячейке, все формулы автоматически пересчитываются. Здесь то же самое - когда приходят новые данные, интерфейс сам обновляется."

### Для объяснения линейной регрессии:
"Если вы видите, что часы каждый день отстают на 1 секунду, можно предсказать, что через месяц они отстанут на 30 секунд. Это и есть регрессия - находим закономерность и экстраполируем."

## ❓ Частые вопросы и ответы

**Q: Почему не JavaScript?**
A: Rust дает гарантии безопасности и производительности, которых нет в JavaScript. Особенно важно для системного программирования.

**Q: Зачем WebAssembly, если есть JavaScript?**
A: WebAssembly работает быстрее и позволяет использовать существующие библиотеки на Rust без переписывания.

**Q: Что такое линейная регрессия простыми словами?**
A: Это способ найти прямую линию, которая лучше всего описывает ваши данные, и использовать её для предсказания.

**Q: Почему проект не запускается на Windows?**
A: Основной демон требует Linux (использует Unix Socket). Но UI можно разрабатывать на Windows, а запускать через Docker или на Linux-сервере.
