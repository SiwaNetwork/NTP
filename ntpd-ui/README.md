# Интерфейс UI Dashboard для NTPD-RS проекта

Веб-интерфейс для мониторинга NTP-сервера на Rust.

## Простой дашборд, чтобы смотреть состояние NTP-сервера в браузере. Показывает метрики, графики и предсказывает уход часов.

## Как построено и работает

```
ntpd-rs демон → Unix Socket → HTTP сервер → Веб-интерфейс в браузере
```

1. Демон `ntpd-rs` пишет данные в Unix Socket
2. HTTP сервер читает из сокета и отдает через REST API
3. Веб-интерфейс запрашивает данные и показывает в браузере

## Что пременил:

- **Dioxus** - UI фреймворк (компилируется в WASM)
- **Axum** - HTTP сервер
- **Tokio** - для асинхронности (применил так как встроен в Dioxus) можно будет и убрать
- **Serde** - для работы с JSON

## Что делает подпроект

- Показывает метрики в реальном времени (Stratum, Offset, время работы)
- Рисует график изменения времени за последние 60 секунд
- Предсказывает, насколько уйдут часы через час (линейная регрессия)
- Показывает список источников времени и статистику


### Что нужно для старта

- Dioxus CLI: `cargo install dioxus-cli`
- Демон `ntpd-rs` должен быть запущен

### Порядок сборки

```bash
# Собираем фронтенд
cd ntpd-ui
dx build --release --platform web

# Собираем и запускаем сервер
cargo build --release --features backend
./target/release/ntpd-ui-server
```

Открой в браузере: `http://localhost:3000`

### Настройки (переменные окружения)

- `NTPD_OBSERVE_SOCKET` - путь к Unix Socket (по умолчанию `/run/ntpd-rs/observe`)
- `HOST` - адрес сервера (по умолчанию `0.0.0.0`)
- `PORT` - порт (по умолчанию `3000`)

## Структура

```
ntpd-ui/
├── src/
│   ├── main.rs      # Фронтенд (Dioxus)
│   ├── server.rs    # Бэкенд (HTTP сервер)
│   ├── math.rs      # Математика для предсказаний
│   ├── types.rs     # Типы данных
│   └── style.css    # Стили
└── Cargo.toml
```

## Для отладки/разработки

```bash
# Фронтенд (с hot reload)
dx serve --platform web

# Бэкенд
cargo run --features backend --bin ntpd-ui-server
```
