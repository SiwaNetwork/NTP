# Участие в пуле NTS

Сетевая защита времени (NTS) - это расширение протокола NTP, направленное на
обеспечение безопасности связи между NTP-клиентами и серверами. Экспериментальный
пул для серверов с поддержкой NTS был недавно создан на
<https://experimental.ntspooltest.org/>

NTPD-rs версий новее 1.7.0-alpha.20251003 поддерживает добавление в этот
пул. Это руководство предполагает, что вы используете версию новее этой,
и уже настроили NTS-сервер, используя инструкции в [нашем руководстве по NTS](./nts.md).

## Добавление вашего сервера

Чтобы добавить NTS-сервер в пул, на веб-сайте пула добавьте доменное имя
сервера на странице `Time sources` после входа в систему. Пул предоставит вам
ключ аутентификации, который пул будет использовать для аутентификации себя на вашем NTS
сервере. Этот ключ нужно будет добавить в конфигурацию ntpd-rs, чтобы разрешить
пулу обрабатывать соединения обмена ключами NTS для вашего сервера.

Чтобы добавить этот ключ, измените конфигурацию ntpd-rs в `/etc/ntpd-rs/ntp.toml`,
добавив в раздел `[[nts-ke-server]]` следующее:

```toml
accepted-pool-authentication-tokens = ["<ВАШ ТОКЕН ЗДЕСЬ>"]
```

После перезапуска вашего сервера он начнет принимать запросы от пула,
и вы начнете видеть, как ваш счет на веб-сайте пула увеличивается. Когда это
происходит, ваш сервер успешно настроен для использования в пуле.
